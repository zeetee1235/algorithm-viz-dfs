📚 힙 정렬의 2단계 핵심 원리

1단계: 최대 힙 구축 (Build Heap) O(N)

마지막 비단말 노드(⌊n/2⌋ - 1)부터 루트(0)까지 역순으로 heapify(sift-down)를 수행하여 부모가 자식보다 큰 최대 힙을 완성합니다.

2단계: 루트 추출 & 정렬 (Sort Down) O(N log N)

루트(항상 최댓값)를 힙의 마지막 원소와 교환하여 정렬 영역에 고정하고, 힙 크기를 1 줄인 뒤 다시 루트에서 heapify를 반복합니다.

시간 복잡도 (최선/평균/최악): O(N log N)
공간 복잡도: O(1) 제자리 정렬
안정 정렬 여부: 불안정 정렬 (Unstable)
의사코드 (Pseudocode) 트래커 실시간 실행 라인
// 1단계: 최대 힙 생성
for i = ⌊n/2⌋ - 1 down to 0:
maxHeapify(arr, n, i)
// 2단계: 최댓값 추출 및 재정렬
for i = n - 1 down to 1:
swap(arr[0], arr[i]) // 루트를 끝으로
maxHeapify(arr, i, 0) // 크기 i로 재정렬
